05 공식 유형자산 재평가 계산 ⌄

2년 후 장부금액 = 30,000

공정가치 = 40,000

⭐ 재평가 직전 장부금액 ↔ 공정가치 비교

07 암기 무형자산 상각 ⌄

유한 내용연수 → 상각 O

비한정 내용연수 → 상각 X, 손상검사

비한정 → 유한으로 변경 가능

잔존가치는 장부금액보다 커질 수도 있으며, 이 경우 상각액이 0이 될 수 있음.

⭐ '잔존가치는 장부금액보다 클 수 없다' → 틀림
08 암기 투자부동산 모형 선택 ⌄

공정가치모형 또는 원가모형을 회계정책으로 선택.

선택한 정책은 원칙적으로 모든 투자부동산에 적용.

단순히 '투자부동산 유형별로 자유롭게 각각 선택'하는 개념이 아님.

⭐ FV모형: 감가상각 X / 가치변동 당기손익
09 암기 FVOCI 지분상품 처분 ⌄

FVOCI로 지정한 지분상품의 평가손익은 OCI.

처분해도 누적 OCI를 당기손익으로 재분류하지 않음.

자본 내에서 대체는 가능.

⭐ 처분이익 당기손익 = 0원

11 공식 누적·비참가 우선주 배당 ⌄

우선주 자본금 2,000,000 × 10% = 연 200,000

전년도 미배당 + 당년도 = 400,000

총 배당 500,000 - 우선주 400,000

보통주 배당 = 100,000

⭐ 누적 = 밀린 배당까지 / 비참가 = 우선배당 후 추가참가 X
12 이해 비누적 우선주 ⌄

비누적이면 전년도에 못 받은 배당은 소멸.

당해연도 우선배당 200,000만 우선주에 배분.

총배당 500,000이면 보통주 = 300,000.

⭐ 비누적 = 밀린 거 안 챙김
13 공식 자본총계 계산 ⌄

기초자본 = 자산 35,000,000 - 부채 13,000,000

= 22,000,000

총포괄이익 = 당기순이익 1,300,000 + OCI 1,100,000

= +2,400,000

유상증자 현금유입 = +600,000

자기주식 취득 = -700,000

주식배당은 자본 내부 대체 → 자본총계 변화 X

⭐ 자본총계 = 기초자본 + 총포괄이익 + 소유주거래 증감
14 암기 라이선스 수익 인식 ⌄

기업이 라이선스 대상 지적재산을 계속 변경·지원해야 하는 의무가 없다면 사용권 성격.

사용권 라이선스는 고객이 사용할 수 있게 되는 시점에 수익 인식.

문제에서는 재녹음 활동을 수행하지 않음.

⭐ 접근권 = 기간 / 사용권 = 시점
15 공식 건설계약 계약자산 ⌄

누적원가 40m + 추가예정원가 60m

총예정원가 = 100m

진행률 = 40 / 100 = 40%

누적수익 = 120m × 40% = 48m

청구액 = 40m

계약자산 = 8m

⭐ 총계약금액 ≠ 총예정원가

17 암기 법인세 일시적차이 ⌄

가산할 일시적차이 → 이연법인세부채

차감할 일시적차이 → 이연법인세자산

미사용 세무상결손금·세액공제 → 요건 충족 시 이연법인세자산

⭐ 미래 세금 줄여주는 것 = 이연법인세자산
18 공식 법인세비용 계산 ⌄

당기 법인세는 당기 과세소득 × 당기세율.

이연법인세는 일시적차이가 소멸할 것으로 예상되는 기간의 세율을 사용.

영구적 차이는 이연법인세를 만들지 않음.

⭐ 당기세금 = 올해 세율 / 이연세금 = 미래 적용세율
19 암기 회계정책 vs 회계추정 변경 ⌄

측정기준 변경 → 회계정책 변경

내용연수 변경 → 회계추정 변경

잔존가치 변경 → 회계추정 변경

감가상각방법 변경 → 회계추정 변경

⭐ 측정기준 = 정책 / 내용연수·잔존가치·상각방법 = 추정
20 암기 가중평균유통보통주식수 ⌄

자기주식은 유통주식이 아니므로 취득 이후 제외.

공정가치 유상증자 → 납입일 기준 가중.

무상증자 → 기초부터 있었던 것처럼 소급 조정.

공정가치 미만 유상증자 → 유상 + 무상 요소로 구분.

⭐ 자기주식 = 유통주식수에서 빼기
21 암기 외화 재무제표 환산 ⌄

자산·부채 → 보고기간 말 마감환율

수익·비용 → 거래일 환율

환율 변동이 유의적이지 않다면 수익·비용에 기간 평균환율 사용 가능.

⭐ 재무상태표 = 마감 / 손익 = 거래일(평균 가능)
